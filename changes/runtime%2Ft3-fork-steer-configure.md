- The runtime uses five T3 tools it never named. Forks let a coordinator, planner, or reviewer start from a framed thread, and `t3_thread_merge_back` returns a fork's reasoning when the source needs it. `t3_thread_configure` escalates a launched owner's model in place. `t3_queue_promote_to_steer` delivers a queued correction into an active turn. `run_scheduled_task_now` runs a tick at once when its event already happened. Visual reports publish tables, timelines, and frontiers through `html_preview` and `html_render`. Orchestrate links forks for sub-coordinators, configure for retries on another model, and visual reports for its checkpoint reply.
- `no-comments` never runs inside a read-only task or reviewer. T3 has no read-only flag, so the skill states the limit itself.
